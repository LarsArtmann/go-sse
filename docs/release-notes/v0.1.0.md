# v0.1.0 Release Notes

**Tag:** `v0.1.0` — 2026-07-23

First public release of `go-sse`, a minimal, type-safe Server-Sent Events library for Go 1.26+.

## What's included

### Core

- **Wire-format serialization** — `WriteEvent`, `WriteHeartbeat`, `WriteRetry` with allocation-minimized byte appends and spec-compliant multi-line `data:` splitting (LF, CRLF, and lone CR)
- **`Stream`** — single-connection lifecycle: SSE headers, mutex-guarded concurrent writes, heartbeat goroutine, `Last-Event-ID` extraction, ordered `OnDisconnect` callbacks, request-context cancellation. Implements `io.Closer`.
- **`Broadcaster[T]`** — generic fan-out hub: non-blocking broadcast with 64-deep subscriber buffers, drop-on-full backpressure, O(1) unsubscribe via channel pointer identity, subscribe/unsubscribe hooks, graceful `Close`
- **`EventStore` + `Replay`** — reconnection replay interface and function for sending missed events on client reconnect
- **Branded `EventID`** — phantom-type branded ID preventing cross-assignment with other string-typed IDs, with `ParseEventID` validation (rejects newlines/CR that corrupt the SSE wire format)

### Quality

- **97.8% test coverage**, all tests pass with `-race`
- **Fuzz tests** for `WriteEvent` and `ParseEventID`
- **Integration tests** with real `httptest.Server` SSE round-trip
- **golangci-lint** clean (gosec, makezero, nolintlint, and more)
- **GitHub Actions CI** (test, lint, vet, coverage)
- **Nix flake** for hermetic build/test/lint/coverage/format

### Developer experience

- **`example/`** directory with a minimal runnable SSE server

## Quick start

```go
broadcaster := sse.NewBroadcaster[sse.Event]()

// SSE endpoint
http.HandleFunc("/events", func(w http.ResponseWriter, r *http.Request) {
    stream := sse.NewStream(w, r)
    defer stream.Close()

    go stream.Heartbeat(stream.Context(), 15*time.Second)

    ch := broadcaster.Subscribe()
    defer broadcaster.Unsubscribe(ch)

    for {
        select {
        case <-stream.Context().Done():
            return
        case evt := <-ch:
            if err := stream.Send(evt); err != nil {
                return
            }
        }
    }
})

// Broadcast from anywhere
broadcaster.Broadcast(sse.Event{Event: "update", Data: "<div>new</div>"})
```

## Stability

This is a `v0` release — the public API may change before `v1.0`. The core types (`Event`, `Stream`, `Broadcaster`, `Replay`) are stable in practice, but breaking changes in minor versions are possible.
