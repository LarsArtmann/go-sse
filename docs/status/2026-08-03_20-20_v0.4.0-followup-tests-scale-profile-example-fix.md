## e) WHAT WE SHOULD IMPROVE

1. **Verify edits took effect before documenting them.** The json v2 flip-flop happened because I trusted the multiedit tool's success message without checking the committed file. After any edit that the auto-commit daemon might race with, re-read the file and verify the change is in the working tree.

2. **Read the golangci-lint config before writing test code.** The `makezero` linter is enabled and catches `make([]T, n)` + index assignment. I should default to `make([]T, 0, n)` + `append` in this project, always. This is a one-time lesson — encode it in AGENTS.md conventions.

3. **The scale profile is a point-in-time snapshot on one machine.** It should be re-runnable in CI (or at least on the developer's machine) with a single command. The benchmark exists and the report has a reproduce command, but there is no automation to catch regressions. A CI benchmark job (even if best-effort) would catch fan-out latency regressions.

4. **No drop counter.** The scale profile report says "observable via a future drop-counter metric" and the ROADMAP lists observability as an exploration. But right now there is zero visibility into how many events a slow subscriber is dropping. This is the single most impactful observability gap for production consumers.

5. **The `stream.go:130` gopls stdversion warning persists.** `json.Marshal requires go1.27 or later (file is go1.26)`. This is a gopls diagnostic I did not touch (correct — I didn't modify stream.go). But it means `SendJSON` uses `json.Marshal` from `encoding/json` (v1), while the rest of the project uses `encoding/json/v2` via `GOEXPERIMENT`. This inconsistency is worth tracking — either `SendJSON` should use v2, or the diagnostic should be suppressed with a comment explaining why v1 is intentional.

6. **The DataStar example has never been rendered in a browser.** Every fix I made to it (`data-style:width`) is verified against the docs reference, but the example is a teaching tool — if a user copies it and it doesn't work, that is a bad first impression. The TODO to point a real client at it is the highest-value remaining item.
