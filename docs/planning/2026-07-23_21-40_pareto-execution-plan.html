05Key Findings from Deep Review

Fixed on spot

splitLines does not handle lone CR per SSE spec

event.go:160 (splitLines) — FIXED in this review

The SSE spec mandates that CR (\r), LF (\n), and CRLF (\r\n) are all valid line endings. The original code only split on \n and stripped a preceding \r. A lone \r without \n was passed through unsplit, corrupting the wire format. Fixed: splitLines now handles all three line-ending styles per spec. Existing tests pass; a new TestWriteEvent_LoneCarriageReturn test is planned (F9.4).

Security

LastEventIDFromRequest bypasses ParseEventID validation

stream.go:201 (LastEventIDFromRequest)

The ParseEventID function exists specifically to reject \n/\r in event IDs (which corrupt the SSE wire format). But LastEventIDFromRequest reads from the untrusted Last-Event-ID HTTP header using NewEventID (no validation). A malicious client can send Last-Event-ID: foo\nbar and get back an EventID containing a newline. If that ID is ever written back to the wire (e.g., echoed in a diagnostic event), it injects additional SSE fields. Fix (M2): validate via ParseEventID, return zero EventID on invalid input.

Duplication

Heartbeat string duplicated between WriteHeartbeat and Stream.Heartbeat

event.go:142 and stream.go:164

The string ": heartbeat\n\n" appears in both WriteHeartbeat and Stream.Heartbeat. Changing one without the other creates a split brain. Fix (M8): extract heartbeatFrame constant, use WriteHeartbeat in Stream.Heartbeat.

Type Safety

Event.Retry is int, allowing negative values

event.go:90 (Retry field)

Retry int allows negative values. The SSE spec says retry is milliseconds (a positive integer). WriteEvent only writes retry when > 0, so negatives are silently skipped, but the type doesn't prevent the impossible state. Fix (M5): change to uint.

Type Safety

EventStore.EventsAfter takes string, not EventID

replay.go:13 (EventsAfter interface)

The EventStore interface uses string for the lastID parameter, losing the branded EventID type safety. Replay calls store.EventsAfter(lastID.Get()) — the .Get() unwrap is the leak. Fix (M6): change to EventsAfter(lastID EventID).

Code Quality

Test helpers reinvent the standard library

stream_test.go:317-334 (contains/startsWith), broadcaster_test.go:414 (itoa)

Hand-rolled contains() (O(n²) recursive) and itoa() (custom integer-to-string) reimplement strings.Contains and strconv.Itoa. Fix (M7): replace with stdlib, delete helpers.

Coverage Gap

WriteRetry has 0% test coverage

event.go:150 (WriteRetry) — 0.0% coverage

The exported WriteRetry function is never called by any test. Fix (M9/F9.3): add TestWriteRetry.

Fragility

errorResponseWriter relies on nil-method-call semantics

replay_test.go:152-161

The writer field is nil-initialized. errorWriter.Write works on a nil pointer because it never dereferences the receiver, but the wiring is fragile and confusing. Fix (M7/F7.5): initialize writer: &errorWriter{}.

♦Strengths to Preserve

This library does many things exceptionally well. These patterns should be maintained, not changed:

+
Allocation-free hot pathWriteEvent uses direct byte appends, not fmt.Fprintf. Benchmarks confirm 0 allocs on the fan-out path. This is the right call for a transport library.
+
Branded EventID typeUsing go-branded-id phantom types prevents cross-assignment with other string IDs. This is exactly the kind of type safety the AGENTS.md philosophy demands.
+
Clean Broadcaster/fanOut splitThe public Broadcaster[T] wraps the unexported transport-agnostic fanOut[T]. Good composition, no leaky abstractions.
+
Non-blocking broadcast with documented drop policyThe select { case ch ← msg: default: } pattern prevents head-of-line blocking. The drop policy is documented and intentional.
+
Excellent concurrency documentationAGENTS.md documents three critical concurrency invariants with precise explanations. This is the gold standard for concurrent Go library docs.
+
Race-testedMultiple race tests with -race. 95.9% coverage with real concurrent scenarios.
+
Hermetic Nix flakeflake.nix provides fully reproducible build/test/lint/format. Zero setup friction.
